# Quantitative Methods Quick Reference Guide

A cross-language practical reference for implementing common statistical and econometric methods in **R, Stata, and Python**.

## Purpose

This repository provides concise, practical references for common quantitative methods, with equivalent implementations across R, Stata, and Python.

The goal is to make it easy to:
- Review the basic concepts and assumptions behind each method
- Quickly reference the syntax for implementing methods in different languages
- Compare implementations across R, Stata, and Python
